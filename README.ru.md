# GlyphFix — починка иконок и глифов для RimWorld 1.7 (Waylith, Android)

[English](README.md) · [简体中文](README.zh-CN.md) · **Русский**

Два бага отрисовки в Android-порте на движке Waylith, два патча, без изменений в движке.

> Раньше назывался `AgentTouchFix`. Код тот же, имя точнее.

## Что исправляется

**1. Пустые иконки в меню строительства.** `ThingDef.uiIcon` превращается в `BaseContent.BadTex`: материал графики разрешается в `CutoutComplexUI`, текстура которого в этом порте не становится читаемой. GlyphFix подгружает иконку прямо из пути текстуры графики в момент отрисовки и снимает материал иконки, который здесь не рендерится.

**2. Пустой квадрат справа от кнопки призыва.** Это гизмо атаки оружия. Когда команда недоступна, игра ставит `lowLight = true`, значение доходит до `Widgets.ThingIcon(grayscale: true)`, и материал собирается из `ShaderDatabase.GrayscaleGUI` (`Misc/GrayscaleGUI`). Порт содержит 262 шейдерные программы с хеш-именами и **не регистрирует эту**, поэтому `ShaderRegistry.Resolve` откатывается на программу по умолчанию, и иконка рисуется как пустое серое поле. GlyphFix принудительно ставит `grayscale = false`; состояние «недоступно» по-прежнему передаётся цветом `GUI.color` — иконка тускнеет, а не исчезает, и снова становится яркой после призыва.

## Стоимость

| | |
|---|---|
| Устойчивое состояние | **16,7 нс** на вызов (голый `HashSet.Contains` — 13,67 нс на том же раннере) |
| Итого | **< 0,1 % одного ядра** при ~30 тыс. вызовов/с |
| Загрузка | без изменений — до главного меню `ThingIcon` не вызывается |
| Память | ≤ 4096 def + ≤ 512 имён материалов, ~0,3 МБ, очищается при перезагрузке данных |

Кэш решений сбрасывается в `PlayDataLoader.ClearAllPlayData` и `HotReloadDefs`, поэтому смена языка не оставляет иконки пустыми навсегда; резервный сторож с интервалом 250 мс прикрывает случай, когда хуки не установились.

## Установка

Положить `GlyphFix` в `Mods/`, включить, перезапустить. Настроек нет.

## Требования

RimWorld 1.7 (движок Waylith). Проверено на Android-порте `com.ports1de.waylith`, Xiaomi 23078RKD5C, Android 14.
